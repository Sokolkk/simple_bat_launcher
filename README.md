# Bat Launcher

A simple GUI launcher for `.bat` files. Pick a folder, see all batch files, run them with one click, or open them in Notepad for editing.

## Features

- Select a folder containing `.bat` files
- Folder path is saved and restored on next launch
- Lists all `.bat` files in the folder
- Run selected file with a single click (or double-click)
- Open selected file in Notepad
- Refresh button to re-scan the folder

## Requirements

- Python 3.8+
- tkinter (included in standard Python from python.org)

No third-party packages needed.

## Usage

1. Save `bat_launcher.py` anywhere on your disk.
2. Run it:

   ```powershell
   py -3.12 bat_launcher.py
